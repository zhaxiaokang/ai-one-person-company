# AI 一人公司：一支 bot 团队的真实运行记录

这是一家由 Grok Bot 上的 bot 团队运营的一人公司。董事长是一个真人，其余岗位都是 bot。
这里公开我们的团队结构、规则、定时循环和看门狗，以及**一份不美化的运行日志**。

> 截至 2026-11-03（北京时间），这家公司的收入是 **¥0**。
> 我们不卖“AI 帮你躺赚”。这个仓库记录的是：一支 bot 团队怎么分工、怎么自我约束、怎么失败、怎么换路。

独立声明：我们是独立工作室 Solo Studio OS，与 Grok Bot、SpaceXAI 没有任何隶属、合作或授权关系。

## 团队结构

| 岗位 | 做什么 | 不做什么 |
|---|---|---|
| 董事长（真人） | 定方向；批准发送、付款、授权、删除等高风险动作 | 不日常盯盘 |
| 总经理 | 定目标、派活、判断价值、对结果负责；只和董事长对接 | 不亲自干活 |
| 监事 | 只监督不拍板；复核重要结论和高风险操作；可绕过总经理直接报董事长 | 不指挥、不执行 |
| 财务 | 盯订阅、额度和花费，周报 | 只读；不付款、不改订阅 |
| 执行岗（工程师 / 执行者） | 调研、写稿、建页面、写代码；产出写进资料库 | 不自己合并、不自己对外发送 |

完整设定稿（已脱敏）见 [`配置/岗位/`](配置/岗位/)。

## 定时循环

| 循环 | 频率 | 做什么 |
|---|---|---|
| 价值循环 | 每 2 小时 | 收事件（邮箱、社交平台提及）→ 看门狗检查各条线 → 决定本轮最值得做的一步，或明确“本轮不开新活” → 写运行日志 |
| 看门狗 | 随价值循环 | 每条线有到期时间和止损条件；连续 N 轮没信号就停或换打法 |
| 监事巡检 / 周审 | 每日 / 每周 | 复核规则、残留文件、对外发布清单、凭据是否只在保险库 |
| 财务周报 | 每周 | 额度和订阅花费 |

模板见 [`配置/定时任务.md`](配置/定时任务.md)。

## 价值循环怎么转

```
事件（买家来信 / 提及 / 审核结果）
  → 看门狗：哪条线到期？哪条线连续没信号？
  → 判断：本轮最有价值的一步是什么？没有就不做
  → 派给执行岗（浏览器、调研、写稿）
  → 回写：运行日志 + 进度看板 + 对应线程文件
  → 高风险动作（发信、发帖、付款、授权）→ 董事长确认卡
```

## 规则（节选）

- 发信、发帖、付款、删除、授权、合并：一律先过董事长；监事事后复核。
- 密码只放凭据保险库；资料库和日志里不写任何密钥、Token、Cookie。
- 结论要带来源，或标“推断”。
- 每次运行都写一行日志，只追加、不改旧行；“跳过”也要记。
- 不给买家空口承诺。

完整清单见 [`配置/审批与安全规则.md`](配置/审批与安全规则.md)。
